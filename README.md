# YouTube Growth Review Tool

A local, privacy-friendly YouTube Analytics review tool for creators. It turns exported YouTube Studio CSV data into a strategic growth report, helping creators understand what drives views, subscribers, packaging performance, and repeatable content formats.

The app runs locally with Python and does not upload analytics data to any third-party service.

## Features

- Upload or paste YouTube Analytics CSV data
- No frontend JavaScript required: reports are generated by a local Python HTTP server
- Supports common YouTube Studio export columns, including:
  - `Video title`
  - `Views`
  - `Subscribers`
  - `Thumbnail impressions`
  - `Thumbnail click-through rate (%)`
  - `Watch time (hours)`
  - `Duration`
- Skips `Total` summary rows automatically
- Estimates average view duration from watch time and views when needed
- Generates strategic review sections:
  - Growth diagnosis
  - True growth engines
  - High-view low-subscriber traffic traps
  - Hidden gems worth repackaging
  - High-CTR packaging winners
  - Topic quadrant analysis
  - Title pattern analysis
  - Reusable title formulas
  - Series and columnization recommendations
  - Next-week content directions
  - Old-video repackaging candidates
  - Concrete action items

## Quick start

Python 3.10+ is recommended. No third-party dependencies are required.

```bash
python youtube_growth_review_server.py
```

Then open:

```text
http://127.0.0.1:8765
```

## Privacy

This tool is designed for local use. Your analytics CSV stays on your machine unless you choose to share it elsewhere.

The repository intentionally excludes CSV, TSV, XLS, and XLSX files by default in `.gitignore` to reduce the risk of accidentally committing private analytics data.
