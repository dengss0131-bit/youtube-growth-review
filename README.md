# 全网新媒体增长复盘工具 / Multi-Platform New-Media Growth Review Tool

A local, privacy-friendly growth review tool for content creators. Turn exported creator-backend data from **YouTube / Douyin (抖音) / Xiaohongshu (小红书) / Bilibili (B站) / WeChat Channels (视频号) / TikTok** into a strategic growth report — helping creators understand what drives views, followers, packaging performance, and repeatable content formats.

The app runs locally with Python (standard library only) and does not upload analytics data to any third-party service.

## 支持平台 / Supported platforms

| 平台 | 自动检测依据（示例字段） |
|---|---|
| YouTube | `Video title` / `Views` / `Subscribers` / `Thumbnail impressions` / `Thumbnail click-through rate (%)` |
| 抖音 | `作品标题` / `播放量` / `完播率` / `涨粉数` / `点赞数` |
| 小红书 | `笔记标题` / `曝光量` / `阅读量` / `收藏` / `涨粉数` |
| B站 | `稿件标题` / `播放量` / `新增关注` / `投币` / `收藏` |
| 视频号 | `视频标题` / `播放量` / `转发` / `涨粉` |
| TikTok | `Title` / `Views` / `Followers gained` / `Average watch time` |

## Features

- Upload or paste backend CSV data from any supported platform
- Automatic platform detection (or manual selection)
- Unified metric layer: views / followers gained / CTR / impressions / retention / engagement
- Falls back to engagement rate (likes + comments + shares + favorites) when a platform does not export CTR
- No frontend JavaScript required: reports are generated by a local Python HTTP server
- Skips `Total` / `合计` summary rows automatically
- Estimates average view duration from watch time and views when needed
- Generates strategic review sections:
  - Growth diagnosis
  - True growth engines
  - High-view low-follower traffic traps
  - Hidden gems worth repackaging
  - High-CTR (or high-engagement) packaging winners
  - Topic quadrant analysis
  - Title pattern analysis
  - Reusable title formulas
  - Series and columnization recommendations
  - Next-week content directions
  - Old-content repackaging candidates
  - Concrete action items

## Quick start

Python 3.10+ is recommended. No third-party dependencies are required.

```bash
python youtube_growth_review_server.py
```

Then open:

```text
http://127.0.0.1:8765
```

## Privacy

This tool is designed for local use. Your analytics data stays on your machine unless you choose to share it elsewhere.

The repository intentionally excludes CSV, TSV, XLS, and XLSX files by default in `.gitignore` to reduce the risk of accidentally committing private analytics data.
