# 全网新媒体增长深度复盘工具使用教程

这是一份面向内容创作者的完整使用教程。你可以用这个工具分析各平台后台导出的数据（YouTube / 抖音 / 小红书 / B站 / 视频号 / TikTok），快速判断账号为什么涨、为什么不涨、哪些内容值得继续做，以及下周应该优先测试什么选题。

## 1. 这个工具适合谁

适合以下类型的创作者：

- YouTube、抖音、小红书、B站、视频号、TikTok 的科技 / 知识 / 生活类博主
- AI 工具测评博主
- 创作者增长类账号
- 出海 / 工具教程类账号
- 想用数据做选题复盘的个人创作者或团队

如果你平时只看播放量、点击率和涨粉数，但不知道如何把这些数据转成下一步内容策略，这个工具会比较有用。

## 2. 这个工具能分析什么

工具会把后台导出数据转换成一份账号增长诊断报告，重点分析：

1. 哪些内容是真正带来账号增长的内容
2. 哪些内容只是播放高，但没有带来涨粉
3. 哪些选题属于"增长引擎"
4. 哪些选题属于"流量陷阱"
5. 哪些低播放内容其实转粉效率高，值得重新包装
6. 哪些标题和封面包装模式更容易获得点击（无 CTR 平台自动改用互动率）
7. 哪些内容系列值得做成固定栏目
8. 哪些旧内容值得二次包装或重做更新版
9. 下周应该优先测试哪些选题方向
10. 账号当前内容策略的主要风险是什么

## 3. 支持平台与识别方式

工具会自动识别平台，也可以手动选择。各平台常用字段名如下：

| 平台 | 典型字段示例 |
|---|---|
| YouTube | `Video title`、`Views`、`Subscribers`、`Thumbnail impressions`、`Thumbnail click-through rate (%)` |
| 抖音 | `作品标题`、`播放量`、`完播率`、`涨粉数`、`点赞数` |
| 小红书 | `笔记标题`、`曝光量`、`阅读量`、`收藏`、`涨粉数` |
| B站 | `稿件标题`、`播放量`、`新增关注`、`投币`、`收藏` |
| 视频号 | `视频标题`、`播放量`、`转发`、`涨粉` |
| TikTok | `Title`、`Views`、`Followers gained`、`Average watch time` |

字段名会自动做归一化匹配（忽略大小写、空格、`%`、括号），所以各平台导出的字段名略有差异也能识别。

## 5. 运行环境

需要：

- Python 3.10 或更高版本
- 浏览器

不需要安装第三方 Python 包。

## 6. 启动工具

进入项目目录后运行：

```bash
python youtube_growth_review_server.py
```

启动成功后，终端会显示类似：

```text
New-media growth review server running at http://127.0.0.1:8765
```

然后打开浏览器访问：

```text
http://127.0.0.1:8765
```

## 7. 用示例数据测试

第一次使用时，建议先用内置示例数据测试。

步骤：

1. 打开 `http://127.0.0.1:8765`
2. 在"数据平台"下拉框选择平台（或保持"自动检测"）
3. 点击页面上的 **使用示例数据**
4. 等待页面生成报告
5. 查看各个分析模块

示例数据是虚构的，不包含任何真实账号数据。

## 8. 从各平台后台导出数据

### YouTube

1. 打开 YouTube Studio
2. 进入 **Analytics / 分析**
3. 点击 **Advanced mode / 查看更多**
4. 选择时间范围（最近 7 天 / 28 天 / 90 天 / 自定义）
5. 维度选择 **Video / 视频**
6. 点击导出，选择 CSV

### 抖音

1. 打开抖音创作者中心（电脑端）
2. 进入 **数据中心 → 内容数据**
3. 选择时间范围，导出作品数据表格（CSV / Excel）

### 小红书

1. 打开小红书创作者中心（电脑端）
2. 进入 **数据中心 → 笔记数据**
3. 选择时间范围，导出笔记数据

### B站

1. 打开 bilibili 创作中心
2. 进入 **数据中心 → 稿件数据**
3. 选择时间范围，导出稿件数据

### 视频号

1. 打开视频号助手（电脑端）
2. 进入 **数据中心 → 视频数据**
3. 选择时间范围，导出视频数据

### TikTok

1. 打开 TikTok Studio / Creator Center
2. 进入 **Analytics → Content**
3. 选择时间范围，导出内容数据

## 9. 推荐导出的字段

工具会自动识别常见字段。为了获得更好的分析深度，建议导出数据包含：

| 字段 | 用途 |
|---|---|
| 标题 | 用于标题模式分析 |
| 播放量 / 阅读量 | 核心播放指标 |
| 涨粉数 / 新增关注 / 新增订阅 | 转粉效率 |
| 点击率 / 曝光量 | 包装效率（部分平台有） |
| 完播率 / 平均观看时长 / 平均阅读时长 | 内容质量 |
| 点赞 / 评论 / 分享 / 收藏 | 互动质量 |

如果缺少部分字段，工具仍然可以运行，但分析深度会下降。没有 CTR 的平台，工具会自动用互动率（点赞+评论+分享+收藏 ÷ 播放量）替代。

## 10. 可选手动补充字段

如果你想获得更准确的策略分析，可以在导出的表格中手动补充以下列（任意列名，工具会识别中文/英文）：

| 字段 | 示例 | 用途 |
|---|---|---|
| `topic` / `题材` | AI productivity / 工具测评 / 教程干货 | 分析题材表现 |
| `series` / `系列` | Tool reviews / 教程系列 / 测评系列 | 分析栏目表现 |
| `thumbnail_type` / `封面类型` | comparison table / 对比清单型 / 风险警示型 | 分析封面类型 |
| `hook_type` / `开头类型` | real test / 痛点解决 / 时间敏感 | 分析开头钩子 |

如果不补充，工具会根据标题做粗略推断。

## 11. 如何上传或粘贴数据

页面提供两种方式：

### 方式一：上传文件

1. 在"数据平台"下拉框选择平台（或保持"自动检测"）
2. 点击文件选择框，选择后台导出的 CSV / 表格
3. 点击 **生成深度复盘报告**

### 方式二：粘贴内容

1. 用文本编辑器打开导出的表格
2. 复制全部内容（含表头）
3. 粘贴到页面文本框
4. 点击 **生成深度复盘报告**

## 12. 报告模块解释

### 12.1 账号增长结论

这一部分会给出整体判断，例如：

- 当前账号主要靠什么题材获取播放
- 哪类题材更能带来涨粉
- 当前问题更像是包装问题，还是选题定位问题
- 是否存在播放高但不涨粉的风险

这部分适合先看，因为它是整份报告的摘要。

### 12.2 真正的增长引擎

这里展示播放量和涨粉效率都比较好的内容。

这类内容通常值得继续复制：

- 做更新版
- 做避坑版
- 做对比版
- 做系列化内容

判断标准不是单纯播放高，而是播放和涨粉转化都不错。

### 12.3 播放高但不涨粉：流量陷阱

这部分会找出播放不低，但涨粉效率偏弱的内容。

这类内容可能存在的问题：

- 标题吸引了泛用户
- 选题和账号定位不够匹配
- 内容没有建立账号信任
- 结尾没有给出关注理由
- 观众只为单个问题而来，看完就走

这类内容不是不能做，但不应该成为账号长期主线。

### 12.4 隐藏宝藏

隐藏宝藏指：播放量不算高，但转粉效率不错的内容。

这类内容值得重点关注，因为它说明：

- 题材对精准用户有价值
- 包装可能不够强
- 系统推荐可能没有充分放量
- 可以通过改标题、改封面、做更新版重新测试

### 12.5 包装胜利

这一部分展示 CTR（或互动率）明显较高的内容。

它适合用来拆解：

- 哪些标题词更容易被点击
- 哪类封面信息更明确
- 观众对什么承诺更敏感
- 哪种表达方式更适合你的账号

注意：CTR 高不等于成功，还要结合涨粉效率和观看表现。

### 12.6 题材四象限

工具会把题材分成四类：

| 类型 | 含义 | 建议 |
|---|---|---|
| 增长引擎 | 播放高，涨粉也强 | 继续做，系列化 |
| 流量陷阱 | 播放高，涨粉弱 | 谨慎做，优化定位 |
| 隐藏宝藏 | 播放低，涨粉强 | 重做包装，再测试 |
| 低优先级 | 播放和涨粉都弱 | 暂时减少投入 |

这部分是决定下周选题的核心。

### 12.7 标题模式拆解

工具会自动识别标题中的常见模式，例如：

- 时间敏感
- 教程型
- 问题解决
- 对比测评
- 强承诺
- 小白导向
- 清单合集

它会告诉你哪些模式的点击率更高，哪些模式更容易带来涨粉。

### 12.8 可复用标题公式

根据标题模式，工具会给出可复用公式，例如：

```text
【最新】+ 明确平台/工具 + 使用前先看 + 常见问题
```

或者：

```text
具体失败场景 + 原因解释 + 排查清单 + 风险提醒
```

这些公式可以作为下次写标题的参考。

### 12.9 栏目化建议

栏目化不是看某一条内容爆了，而是看某类内容是否可以长期解决同一类用户问题。

适合栏目化的内容通常具备：

- 样本不止一条
- 播放表现稳定
- 涨粉效率不差
- 观众问题可以持续延展
- 标题和封面可以形成固定模板

### 12.10 下周具体选题方向

工具会基于当前数据给出下周建议，例如：

- 某题材做更新版
- 某题材做避坑版
- 某题材做对比版
- 某题材做实测版

这部分可以直接作为下周选题会的初稿。

### 12.11 旧内容二次包装清单

这部分会列出值得重做标题、封面或更新版的内容。

优先处理：

- 转粉效率高但播放低的内容
- 点击低但题材价值高的内容
- 旧内容仍有搜索需求的内容
- 可以做新版教程的内容

### 12.12 可执行动作

这一部分会给出更直接的行动建议，例如：

- 哪类内容要继续做
- 哪类内容要减少
- 哪些标题模式要复用
- 哪些旧内容要重做
- 下周应该如何安排内容组合

## 13. 如何根据报告做内容决策

建议每周按照这个顺序看报告：

1. 先看账号增长结论
2. 再看题材四象限
3. 找出增长引擎
4. 找出流量陷阱
5. 找出隐藏宝藏
6. 拆高点击标题
7. 选择 3-5 个下周选题
8. 选 1-2 条旧内容做二次包装

不要只看播放量。更重要的是：

```text
播放量 × 点击率 × 涨粉效率 × 账号定位匹配度
```

## 14. 建议的每周工作流

推荐每周复盘一次：

1. 周一导出最近 7 天或 28 天数据
2. 上传到工具生成报告
3. 标记增长引擎和流量陷阱
4. 选出下周 3 个主选题
5. 选出 1 个旧内容做重包装
6. 更新你的标题公式库
7. 下周继续验证

## 15. 常见问题

### 15.1 为什么有些内容没有平均观看百分比

如果导出数据没有平均观看百分比，工具会尝试用观看时长反推平均观看时长。

### 15.2 为什么题材分类不准确

如果数据没有 `topic` / `题材` 字段，工具只能根据标题做粗略推断。

想提高准确性，可以手动补充：

```text
topic / 题材
series / 系列
thumbnail_type / 封面类型
hook_type / 开头类型
```

### 15.3 为什么报告和我的主观判断不完全一致

工具只能基于导出的数据判断。它不知道内容质量、观众评论语气、发布时间、外部热点等因素。

建议把工具结果当作复盘起点，而不是最终答案。

### 15.4 真实数据会不会上传到外部服务器

不会。这个工具在本地运行，数据只在你的电脑上处理。

除非你主动把数据上传到别的平台，否则工具不会把数据发送到第三方服务。

### 15.5 平台检测不准怎么办

如果自动检测识别错误，可以在页面"数据平台"下拉框手动选择正确的平台。

## 16. 安全建议

如果你要把项目上传到 GitHub，请注意：

- 不要上传真实的后台导出数据
- 不要上传包含个人路径的配置文件
- 不要上传 `.env`
- 不要上传账号、Token、Cookie
- 不要上传未脱敏的账号商业数据

项目默认 `.gitignore` 会忽略常见表格数据文件，但仍建议上传前检查一遍。

## 17. 总结

这个工具的核心价值不是告诉你"哪条内容播放高"，而是帮助你判断：

```text
哪些内容值得继续投入，哪些只是短期流量，哪些可以变成长期账号资产。
```

如果你持续每周使用，它可以帮助你逐步建立自己的账号增长模型。
